# ADR-0003: Composio Corpus Excluded from v8.0

- **Status:** Accepted
- **Date:** 2026-04-27
- **Decision-Driver:** Franz Paul (benevolent dictator)
- **Sprint:** v8.0 14-day sprint (2026-04-28 to 2026-05-11)
- **Related:** [Spec](../specs/2026-04-27-v8-product-completion.md) §5

## Context

The v8.0 evaluation corpus needs ~150–200 SKILL.md files to give the AI-Eval pillar enough surface to be credible. The Korpus-Inventar Subagent Report (2026-04-27) surveyed five candidate sources:

- **Anthropic official skills:** 13 files. **NOASSERTION (mixed)** per GitHub API; per Anthropic's `THIRD_PARTY_NOTICES.md`, **text-only files** (`.md`, source-available code) are MIT-compatible, but **`docx/pdf/pptx/xlsx` files are source-available only** and must be excluded from any redistributable corpus. Schliff includes only the 13 text-only Anthropic skills.
- **Rezvani's curated skills repo:** 108 files, MIT licensed, clean.
- **Composio agent-skills repo:** 864 files — by far the largest single source — but the GitHub API returns NOASSERTION and the repository contains no LICENSE file.
- **Schliff dogfood corpus:** ~20 files from the schliff repo itself (own SKILL.md, internal skills).
- **Synthetic variations:** ~50 files generated by perturbing the above (token-noise, structural breaks) for stress-testing the deterministic linter.

The Composio corpus is tempting: it would 5x the dataset and skew it toward integration-heavy real-world skills. But the missing LICENSE file is a hard problem. Under default copyright doctrine, "no license" means "all rights reserved" — derivative works (which an evaluation corpus arguably is) are prohibited. Two mitigations were considered: (a) open a license-clarification issue with a 7-day deadline, or (b) ship anyway with a disclaimer. Both fail closer review.

The license posture across the candidate sources is therefore not uniform: **Composio (no LICENSE) is excluded; Anthropic (mixed, but text-only is MIT-compatible) is included with binary-file exclusion; Rezvani (MIT) is included as-is.** This distinction is load-bearing: "no LICENSE" defaults to all-rights-reserved (uniformly excluded), whereas "mixed/NOASSERTION with explicit per-file notices" can be safely partitioned into the redistributable subset.

## Decision

1. **Corpus v1 = 191 skills:** Anthropic 13 + Rezvani 108 + Schliff-dogfood ~20 + synthetic variations ~50.
2. **Composio (864 skills) excluded from v8.0.** No exceptions, no disclaimer-shipping.
3. **License clarification** can be opened as a community issue post-v8.0 launch, but is **not on the critical path** and is **not a blocker** for any v8.0 deliverable.
4. **Composio integration deferred to v8.1**, contingent on receiving an OSI-approved license (MIT, Apache-2.0, or BSD) from upstream.

## Consequences

**Positive:**

- Zero legal risk on launch; corpus is provably clean.
- Forces tighter focus on the 191-skill set — sufficient for ADR-0001's failure-mode coding (n=30 sample) and Phase P3 calibration (n=100–150 holdout per ADR-0002).
- Establishes a clean precedent: license-first corpus hygiene is a measurement-layer credibility signal.

**Negative:**

- Corpus is ~4.5x smaller than the maximum-feasible alternative; some long-tail failure modes (especially integration-skill-specific ones) likely under-represented.
- Schliff loses the "evaluated against ~1000 skills" headline number; v8.0 ships with "evaluated against ~190 skills, all clean-licensed".

## Alternatives Considered

1. **Open license-clarification issue with 7-day deadline** *(rejected).* Creates an external dependency on the v8.0 critical path. Empirically, license clarifications from busy upstream maintainers rarely arrive within 7 days; the "soft deadline" tends to slip and force a late-sprint re-plan. Better to assume zero response and plan v8.1 explicitly.
2. **Use anyway with "research use only" disclaimer** *(rejected).* "All rights reserved" is the legal default for no-LICENSE repos in most jurisdictions; a unilateral disclaimer does not create a license. Unacceptable risk for a measurement-layer product whose entire credibility rests on rigour.
3. **Mirror Composio + relicense as MIT** *(rejected).* Same legal problem, just hidden under another commit. Forking does not launder copyright.
